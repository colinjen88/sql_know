# AI Agents (智能體)

AI Agents 是指能夠利用 LLM 進行推理，並在此基礎上自主規劃步驟、使用工具（Tooling）來達成複雜目標的系統。

## 🤖 智能體 vs. 聊天機器人
- **聊天機器人**：對話 -> 模型回答。
- **智能體**：目標 -> 模型思考 -> 調用工具（例如搜尋 Google）-> 觀察結果 -> 重新思考 -> 達成目標。

## 🏗️ 核心框架
1.  **規劃 (Planning)**：模型能將大目標拆解為子任務（如 ReAct 模式）。
2.  **記憶 (Memory)**：短期記憶（Context Window）與長期記憶（Vector DB）。
3.  **工具使用 (Tool Use)**：能寫程式、看行事曆、操作瀏覽器。

## 🚀 知名專案
- **AutoGPT / BabyAGI**：早期的自主循環嘗試。
- **LangGraph**：用於建立複雜循環與狀態控制的 Agent。
- **CrewAI**：多智能體協作框架（多個 AI 分飾 PM、工程師、QA 來完成專案）。

## ⚠️ 挑戰
- **循環成本**：Agent 可能陷入無限迴圈或過度調用 API。
- **不可預測性**：Agent 的行為軌跡有時難以完全控制。
