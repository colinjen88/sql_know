# Prompt Engineering (提示工程)

提示工程是優化對話模型（LLM）輸入的藝術與科學，旨在讓模型更精確、更穩定地執行特定任務。

## 🏗️ 核心架構 (CO-STAR 框架)
一個優秀的 Prompt 通常包含以下元素：
- **Context (上下文)**：背景資訊。
- **Objective (目標)**：具體要執行的任務。
- **Style (風格)**：希望模仿的角色或語氣。
- **Tone (語調)**：正面、中立或嚴肅。
- **Audience (受眾)**：誰會看這份內容。
- **Response (回應格式)**：JSON, Markdown, 表格等。

## 🚀 技巧清單
1.  **角色設定 (Role Prompting)**：給予模型一個身份，如「你是一位資深的 SQL 專家」。
2.  **分隔符使用**：使用 `###`, `---` 或 XML 標籤如 `<text>` 來隔開指令與數據。
3.  **零樣本與少樣本**：從簡單提問到提供範例。
4.  **思維鏈 (CoT)**：讓模型寫下推理過程。

## ⚠️ 避免模糊
- **壞 Prompt**：寫一個關於數據庫的文章。
- **好 Prompt**：請以技術部落格作者的身份，撰寫一篇 500 字的文章，解釋 SQL 中的「事務 (Transaction)」概念與其重要性。受眾是剛入行的前端工程師。
