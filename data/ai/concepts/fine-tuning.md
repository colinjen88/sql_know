# Fine-tuning (微調)

Fine-tuning 是在一個已經訓練好的大規模模型（Base Model）基礎上，使用特定的、較小規模的領域數據集進行進一步訓練的過程。

## 🎯 什麼時候需要微調？
RAG 適合提供「外部知識」，而微調適合：
- **改變輸出風格**：讓 AI 說話像你的品牌風格。
- **精確格式控制**：模型始終無法正確產出某種複雜的 XML。
- **學會新詞彙**：特定的行業術語或縮寫。
- **提升效能**：讓小型微調模型達到與大型通用模型相當的效果。

## 📐 實作流程
1.  **準備數據 (Dataset)**：通常是上千組 `{"prompt": "...", "completion": "..."}`。
2.  **訓練**：在雲端 GPU 或 OpenAI 平臺上啟動微調任務。
3.  **評估**：對比 Base 模型與 Fine-tuned 模型在驗證集上的表現。

## ⚠️ 缺點
- **成本高**：訓練與託管微調模型通常比直接調用 API 貴。
- **知識過時**：模型學到的知識在訓練完那一刻就停止更新了。
