# 文本分類器 (Text Classifier)

這是 NLP 中最成熟的應用之一，旨在將大量的非結構化文本自動歸類到預定義的標籤中。

## 🎯 應用場景
- **工單系統**：自動判斷客戶問題是「帳務問題」、「技術故障」還是「一般諮詢」。
- **內容審核**：識別「有害言論」、「垃圾郵件」或「正常內容」。
- **新聞彙整**：將新聞歸類為「政治」、「科技」、「體育」。

## 🚀 實作要點

### 1. 標籤明確化
在 Prompt 中列出所有可用的標籤，並給予每個標籤簡短的定義。
> 標籤：[A] - 描述 A；[B] - 描述 B。

### 2. 少樣本 (Few-Shot) 範例
提供 3-5 個具有代表性的範例對。
```text
Text: 我想要退貨，因為衣服尺寸不合。
Label: 退換貨申請

Text: 請問可以用信用卡支付嗎？
Label: 支付與帳務
```

### 3. 強制格式輸出
使用 JSON Mode 或限制輸出僅能包含標籤名稱，以利程式自動化處理。
> 指令：請僅輸出標籤名稱，不要解釋。

## 🛠️ 進階技巧
- **置信度評分**：要求模型輸出它對該分類的信心（0-1）。
- **多標籤分類**：允許一個文本同時屬於多個標籤。
- **Zero-shot 分類**：利用模型強大的常識直接進行分類（如 GPT-4）。
