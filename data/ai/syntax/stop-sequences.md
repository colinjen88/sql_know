# Stop Sequences (停止序列)

Stop Sequences 是開發者定義的一組字串，當模型產出遇到這組字串時，會立即強制停止生成。

## 🛑 為什麼需要它？
1.  **防止模型過度廢話**：例如你只需要模型回答一小段，可以用換行符 `\n` 作為停止序列。
2.  **控制輸出格式**：在 Few-shot 提示中，通常使用 `User:` 或 `###` 作為停止點，防止模型自顧自地演起對方的對話。
3.  **節省 Token 成本**：當目標資訊已經達成，立即停止可以減少不必要的 Token 消耗。

## 🚀 範例
如果你正在設計一個聊天機器人，你的提示如下：
```text
User: 你好。
Assistant: 哈囉！有什麼我可以幫你的嗎？
User: 今天的日期是？
Assistant:
```
此時你可以將 **"User:"** 設為 Stop Sequence。這樣 AI 寫完日期後，就不會手癢繼續幫你寫下一句 "User: 謝謝"。

## 🛠️ 配置限制
大部分主流 API（如 OpenAI）允許你設定最多 **4 個** 停止序列。
常見的停止序列包括：
- `["\n", "User:", "###", "Q:"]`
