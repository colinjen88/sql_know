# Temperature (溫度參數)

Temperature 是一個用於控制 LLM 輸出隨機性（Randomness）的核心參數。

## 🌡️ 數值含義
數值範圍通常在 **0.0 到 2.0** 之間（大部分 API 建議在 0 到 1 之間）：

- **0.0 (或接近 0)**：最穩定、最嚴謹。模型每次都會選擇機率最高的 Token。適合解決方案唯一的問題，如「寫程式」、「數學計算」、「事實擷取」。
- **0.7 - 1.0**：平衡。模型會嘗試一些稍微低機率但也合理的詞，增加流暢度與變化感。適合「創意寫作」、「閒聊」、「摘要」。
- **1.0 以上**：極度發散。內容可能變得非常混亂且不穩定。

## 🛠️ 如何選擇？

| 任務類型 | 建議 Temperature | 說明 |
| :--- | :--- | :--- |
| **程式碼生成** | 0.0 - 0.2 | 需要邏輯嚴密，語法精確。 |
| **資料提取** | 0.1 | 確保提取的資訊真實存在，不加修飾。 |
| **客服回覆** | 0.5 | 保持專業感的同時，語氣不至於過於生硬。 |
| **創意寫作** | 0.8 - 1.0 | 需要靈感與詞彙多樣性。 |

## 💡 注意事項
Temperature 並不會改變模型「知道什麼」，它只是改變了模型如何「選擇」下一個字。
