# Seed (種子值)

Seed 是一個用於確保 LLM 輸出「可重現性」（Reproducibility）的進階參數。

## 🌱 運作原理
LLM 的輸出在本質上是具有隨機性的。即使 Temperature 設為 0，有時受限於硬體浮點運算的隨機性，仍可能產生微小差異。
透過設定一個固定的整數作為 Seed（例如 `42`），你可以要求模型在相同的輸入與參數下，盡可能產生相同的輸出。

## 🎯 應用場景
1.  **測試與除錯**：當你發現一個有趣的 Bug 或模型回應時，固定 Seed 可以讓你穩定地重現該結果。
2.  **單元測試**：在自動化測試中，確保預期的輸出格式不會因為隨機性而發生非預期的變化。
3.  **效能對比**：在比較不同的 Prompt 效果時，固定 Seed 可以消除隨機干擾因素。

## 🛠️ 如何使用
在 API 調用中加入 `seed` 欄位：
```json
{
  "model": "gpt-4o",
  "messages": [...],
  "temperature": 0.7,
  "seed": 12345
}
```

## ⚠️ 注意事項
儘管設定了 Seed，模型供應商有時會更新後端模型或硬體架構，這可能會導致即便是相同的 Seed 也會產出不同的結果。Seed 僅能保證「短期」或「同版本」下的高度一致性。
