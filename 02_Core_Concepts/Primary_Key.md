# Primary Key (主鍵)

## 一句話解釋 (ELI5)
> 主鍵就是每一筆資料的「身分證字號」，**絕對不會重複、不能為空**，用來唯一辨識一筆資料。

## 生活化比喻 (Analogy)
* 像是每個人的**身分證字號** — 每人獨一無二，不可能兩個人共用同一組
* 像是圖書館每本書的**ISBN** — 就算書名相同（例如不同版次），ISBN 也不會重複
* 像是每張發票的**發票號碼** — 就算金額一樣，發票號碼一定不同

## 為什麼重要？ (Why it matters)
* **沒有主鍵的災難：** 如果 `tasks` 表格裡有兩筆「買牛奶」，你無法精確地「只更新其中一筆」
* **保證資料唯一性：** 資料庫會自動阻止你插入重複的主鍵值
* **是關聯的基礎：** Phase 2 學 JOIN 時，兩張表必須靠主鍵 + 外鍵連接


## 在 PostgreSQL 中的用法
```sql
-- 使用 SERIAL + PRIMARY KEY 自動產生遞增主鍵
CREATE TABLE tasks (
    id SERIAL PRIMARY KEY,  -- 自動產生 1, 2, 3...
    title TEXT NOT NULL
);

-- 用主鍵精確操作資料（最安全的 WHERE 條件）
UPDATE tasks SET is_completed = TRUE WHERE id = 1;
DELETE FROM tasks WHERE id = 3;
```
